# Calculadora RMR14 Web Completa

Incluye:
- index.html listo para GitHub Pages.
- Imágenes coherentes según método de excavación:
  - Perforación y voladura tradicional + transporte con scoop.
  - Excavación mecánica con TBM.
- GIFs de sostenimiento según clase RMR14.
- Guía de fórmulas.
- Cálculo de RMRb14, F0, Fe, Fs y RMR14.

Para usar:
1. Descomprime el ZIP.
2. Sube index.html y la carpeta assets a la raíz del repositorio.
3. Activa GitHub Pages.
